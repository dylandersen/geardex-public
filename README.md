## Overview

GearDex is a working system for managing camera equipment and production prep. It helps photographers, filmmakers, studios, and rental-minded teams keep gear records, documents, loans, maintenance, shoot details, and packing decisions in one place.

This repository is the public home for:

- Web app and macOS app issue tracking
- Product-facing roadmap items
- Official GearDex macOS releases
- Release feedback and support guidance

This repository does not contain GearDex application source code.

## Product

GearDex is available as a web app at [www.geardex.app](https://www.geardex.app). The macOS app is distributed through this repository's [Releases](https://github.com/dylandersen/geardex-public/releases) page.

Core workflows include:

- Gear inventory for camera bodies, lenses, accessories, filters, and drones
- Rigs and kits for repeatable pack lists
- Documents for receipts, warranties, insurance records, manuals, and production files
- Maintenance tracking and service history
- Loan tracking for outgoing and incoming gear
- Shoot planning with locations, schedules, manifests, permits, release forms, and invoices
- Studio collaboration for shared workspaces
- Iris assistant features for gear and workflow support

## macOS Releases

Download the latest macOS build from [GearDex Releases](https://github.com/dylandersen/geardex-public/releases/latest).

Use the build that matches your Mac:

- Apple Silicon: use the `arm64` DMG
- Intel: use the standard macOS DMG

Pre-release builds are published for early testing. Read the release notes before installing a pre-release build, especially when local data, imports, or app update behavior are mentioned.

For release channel details, see [RELEASES.md](RELEASES.md).
For current public release notes and caveats, see [KNOWN_ISSUES.md](KNOWN_ISSUES.md).

## Reporting Issues

Use the issue forms so reports arrive with the details needed for triage:

- [Bug report](https://github.com/dylandersen/geardex-public/issues/new?template=bug_report.yml): reproducible web or macOS problems
- [Feature request](https://github.com/dylandersen/geardex-public/issues/new?template=feature_request.yml): product ideas and workflow gaps
- [Pre-release feedback](https://github.com/dylandersen/geardex-public/issues/new?template=release_feedback.yml): feedback from macOS beta builds

Good reports include:

- The surface affected: web app, macOS app, or both
- Browser, macOS version, and GearDex app version where relevant
- Clear reproduction steps
- Expected and actual behavior
- Screenshots or logs with private details removed

## Repository Scope

This public repository is intentionally small. It should contain only:

- Product and support documentation
- GitHub issue templates
- Brand assets needed by the public repository
- macOS release artifacts attached to GitHub Releases

Please do not open pull requests with application code. Product development happens in the private GearDex codebase.
