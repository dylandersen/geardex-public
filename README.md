This repository is the public home for **GearDex** issue tracking for both the web app and macOS app, plus official **macOS app** releases and auto-update metadata.

Website: [www.geardex.app](https://www.geardex.app)

## Purpose

Use this repository to:

- Report issues for the GearDex web app at [www.geardex.app](https://www.geardex.app)
- Report issues for the GearDex macOS app
- Request features for the web app or macOS app
- Download official macOS app releases and pre-releases

## What GearDex Does

GearDex helps photographers and videographers:

- Track camera gear inventory and value
- Log maintenance history and service details
- Manage gear loans and returns
- Plan shoots, shot lists, call details, and prep workflows
- Store documents and notes tied to equipment
- Use Iris AI assistant features for gear and workflow help

## Downloads

- Latest macOS app release: [Download GearDex for macOS](https://github.com/dylandersen/geardex-public/releases/latest)
- Pre-release/beta builds: [GearDex Releases](https://github.com/dylandersen/geardex-public/releases) (look for the **Pre-release** label)

The macOS app is Developer ID signed and Apple-notarized. Install by opening the DMG and dragging `GearDex.app` into Applications.

Apple Silicon Macs should use the `arm64` DMG. Intel Macs should use the standard macOS DMG.
